Handoff: PV Generation Forecasting                                                                                                                                                                                                         
                                                                                                                                                                                                                                            
 Status: Design discussion only. No code or files have been created.                                                                                                                                                                        
                                                                                                                                                                                                                                            
 Goal and confirmed constraints                                                                                                                                                                                                             
                                                                                                                                                                                                                                            
 - Use Open-Meteo irradiance to predict PV output up to 24 hours ahead.                                                                                                                                                                     
 - There are three PV production sensors, one per panel grouping. Each reports watts at five-minute intervals; the groups have different azimuths.                                                                                          
 - The inverter is shared and oversized; clipping is not expected.                                                                                                                                                                          
 - Shading occurs at certain times of day.                                                                                                                                                                                                  
 - Do not train on historical forecasts. Train the PV model using measured generation and Open-Meteo historical best-estimate irradiance. Use forecast irradiance only as input when making future predictions.                             
                                                                                                                                                                                                                                            
 Historical irradiance                                                                                                                                                                                                                      
                                                                                                                                                                                                                                            
 Open-Meteo’s Historical Weather API (https://open-meteo.com/en/docs/historical-weather-api) returns hourly solar radiation for Adelaide over the relevant generation-history period. The archive is reanalysis, not an on-site irradiance  
 measurement. ERA5 is documented from 1940; ECMWF IFS from 2017. Both cover the three-year period. Compare them on a time-based holdout and use one source consistently.                                                                    
                                                                                                                                                                                                                                            
 For each panel group, request global_tilted_irradiance with that group’s tilt and azimuth. It is an hourly mean in W/m² for the preceding hour. Open-Meteo’s azimuth convention is 0° south, −90° east, +90° west, ±180° north. The API    
 returns grid-cell weather, so use the home’s coordinates rather than Adelaide’s city-centre coordinates.                                                                                                                                   
                                                                                                                                                                                                                                            
 Candidate model                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
 A reasonable first ML option is one gradient-boosted tree model per group (LightGBM or CatBoost are candidates, not a final choice).                                                                                                       
                                                                                                                                                                                                                                            
 - Targets: the measured five-minute watts for each group.                                                                                                                                                                                  
 - Features: that group’s tilted irradiance, sun azimuth/elevation at the sample time, and optionally temperature and wind.                                                                                                                 
 - Sun position is important so the model can learn recurring, group-specific shading.                                                                                                                                                      
 - No inverter cap is needed; total predicted watts are the sum of the three group predictions.                                                                                                                                             
                                                                                                                                                                                                                                            
 Three years of five-minute data is about 315,000 samples per group if coverage is complete—manageable on a CPU.                                                                                                                            
                                                                                                                                                                                                                                            
 Five-minute forecasts with hourly irradiance                                                                                                                                                                                               
                                                                                                                                                                                                                                            
 Keep the five-minute PV data as the training targets. Hourly irradiance limits the weather detail available, but it does not force the model’s output timestamps to be hourly.                                                             
                                                                                                                                                                                                                                            
 A possible approach is to shape each hourly irradiance value across its twelve five-minute intervals using the group’s clear-sky solar curve, normalized so those sub-hour values still average to the supplied hourly value. The model    
 then uses that shaped irradiance plus the exact five-minute sun position to predict watts.                                                                                                                                                 
                                                                                                                                                                                                                                            
 This can represent the changing sun angle and repeatable shade within an hour. It cannot predict an unexpected cloud passing during that hour; the five-minute curve is an estimate, not a five-minute cloud forecast.                     
                                                                                                                                                                                                                                            
 Validation and caveats                                                                                                                                                                                                                     
                                                                                                                                                                                                                                            
 - Split training and validation by date, not randomly.                                                                                                                                                                                     
 - Compare predictions per group and in total; track five-minute watt error and daily kWh error.                                                                                                                                            
 - Check whether the sensor values are instantaneous five-minute readings or interval averages before integrating them into kWh.                                                                                                            
 - Historical validation against reanalysis measures the PV model’s response to that reanalysis. Errors in future forecast irradiance remain a separate source of prediction error.                                                         
                                                                                                                                                                                                                                            
 Open-Meteo’s Forecast API (https://open-meteo.com/en/docs) can provide the runtime irradiance. In checks for Adelaide, explicit IFS and the default forecast returned solar data; explicit ACCESS-G returned nulls and its model page      
 (https://open-meteo.com/en/docs/bom-api) noted a BOM open-data suspension. That availability is time-sensitive and should be rechecked later.
